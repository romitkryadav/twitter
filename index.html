Quality and Format

Where multiple resolutions are available for a post, each one is listed separately so you can choose. Files download as standard MP4. The quality ceiling is set by whatever the original poster uploaded — this tool doesn't add resolution that isn't already there.

When a Video Won't Download

  • The account is private. This tool only works with posts publicly visible without logging in.
  • The post was deleted or the link is incomplete. Go back to X and copy the link again.
  • The post contains only images or text. There's no video to extract in that case.
  • The URL format is wrong. Make sure it's an x.com or twitter.com status link.

Using What You Download

Downloading a public video for personal use is different from reposting or redistributing it. Copyright stays with whoever made it. If you plan to reuse a video, get permission from the creator first.
