How to Download an X Profile Picture

Three steps to find and save a profile picture from a public X account.

Copy the profile link

Open X (Twitter), go to the public profile, and copy the URL from your browser's address bar or use the share menu.

Paste it above and click Get Profile Picture

Paste the URL or type the @username into the input box and click the button. The profile preview appears if the account and image are publicly available.

Download the profile picture

Preview the image, then select Download Image to save the available profile picture file to your device.

Download a profile picture from Twitter or X

This Twitter DP downloader lets you preview and save the profile picture associated with a publicly accessible X account. Enter the account’s username or profile URL, review the result, and choose the download option.

Enter a username or profile link

You can enter a username such as @username or a profile URL such as x.com/username. Links using the older twitter.com domain are also supported. Check the spelling and make sure the link points to a profile rather than a post.

Image quality and dimensions

The tool provides the profile image version available from the public account. The dimensions and image quality depend on the image and source data X makes available. The downloader does not add detail or upscale a smaller image.

Save the image on a phone or computer

Use the page in a modern mobile or desktop browser. After previewing the profile picture, select Download Image. Your browser may ask where to save it; otherwise, check the browser’s downloads list or your device’s Downloads folder.

Why a profile picture may not appear

  • Username or link is incorrect: Check the spelling, remove extra characters, and use a profile URL rather than a post link.
  • Profile is unavailable: Deleted, suspended, protected, or sign-in-restricted accounts may not return a profile image.
  • No custom image is available: Some accounts use a default avatar or have no accessible profile image.
  • Temporary loading issue: If the profile is public but no image appears, try again later.

The tool does not bypass account privacy settings. Downloading an image does not grant permission to repost or reuse it; ask the account holder when permission is required.
