What is an X Image Downloader?

An X Image Downloader is a high-speed utility engineered to retrieve and inspect public X (Twitter) posts, locate the highest publicly exposed picture files on the CDN, and present them for immediate full-quality preview and download.

🎯

Highest Original Quality

When users upload images to X, the platform generates multiple size variants. This tool automatically requests the highest original quality format (name=orig / 4096px) without compression or artificial upscaling.

🛡️

Can I Download from Private Tweets?

No. This tool strictly respects security and privacy boundaries. It only functions with publicly accessible X posts. It does not bypass login forms, access controls, private accounts, or CAPTCHA.

Cloudflare Worker Architecture & Deployment Guide

1. System Architecture Overview

The application relies solely on HTML, CSS, Vanilla JavaScript, and a serverless Cloudflare Worker. No X API keys, database, or rate-limiting dependencies are required.

User Browser (HTML + CSS + Vanilla JS) ↓ GET /api/x-images?url=<TWEET_URL> Cloudflare Worker Edge Handler (worker.js) ↓ Public Syndication / Metadata Fetch Public X (Twitter) CDN <pbs.twimg.com> ↓ Extract Highest Quality (name=orig) JSON Response to Frontend Preview ↓ GET /api/x-image-download?url=<IMAGE_URL> Safe Streaming Streamed Direct Download

2. Cloudflare Worker Deployment Instructions

Deploying worker.js using Wrangler CLI:

# 1. Install Wrangler npm install -g wrangler # 2. Login to your Cloudflare account wrangler login # 3. Deploy the worker directly wrangler deploy worker.js --name x-image-downloader

Alternatively, in the Cloudflare Dashboard:

  • Navigate to Workers & Pages > Create Application > Create Worker.
  • Paste the contents of worker.js into the editor.
  • Click Save and Deploy.

3. Cloudflare Pages Deployment Instructions

To deploy the frontend (index.html, style.css, script.js):

  • In the Cloudflare Dashboard, go to Workers & Pages > Create > Pages.
  • Connect your Git repository or use Direct Upload to drag-and-drop the files.
  • Set output directory to . (root).

4. Worker Route & CORS Configuration

Bind your Worker to your custom domain or Pages project in wrangler.jsonc:

{ "name": "x-image-downloader", "main": "worker.js", "compatibility_date": "2024-04-01", "routes": [ { "pattern": "twitter.threadsgrab.com/api/*", "zone_name": "twitter.threadsgrab.com" } ] }

The worker returns standard permissive CORS headers (Access-Control-Allow-Origin: *) to enable requests from your frontend.

5. Testing Instructions (Live Worker)

Test the live endpoints via curl:

# Test Live Worker Health Check curl "https://ximage.romitkr3018.workers.dev/health" # Test Image Extraction curl "https://ximage.romitkr3018.workers.dev/api/x-images?url=https://x.com/TheEllenShow/status/440322224407314432" # Test Streaming Image Download curl -I "https://ximage.romitkr3018.workers.dev/api/x-image-download?url=https://pbs.twimg.com/media/BhxWutnCEAAtEQ6?format=jpg&name=orig"

6. Security & SSRF Protection

The worker implements rigorous security controls:

  • Strict Domain Allowlist: Only permits target URLs from x.com and twitter.com.
  • CDN Whitelist: Image downloads are strictly restricted to pbs.twimg.com and ton.twitter.com.
  • Anti-SSRF: Rejects local IP ranges (127.0.0.1, 10.x.x.x, 192.168.x.x), non-HTTPS schemes, and non-whitelisted destinations.
  • Safe Stream Buffer: Streams responses without buffering entire multi-megabyte payloads in Worker memory.
